# 数式フリック — Android IME

数式や論理記号を入力するための Android キーボード。Android 8.0 以降。

## 使い方

1. APK を Android 端末にインストールし、「数式フリック」を開く。
2. 「1 キーボードを有効にする」で、Android の設定画面にある「数式フリック」をオンにする。
3. アプリへ戻り「2 数式フリックを選ぶ」で選択し、練習欄をタップする。
4. キー中央をタップすると大きな文字、上下左右へフリックすると周囲の小さな文字を入力。上のタブで種類を切り替える。
5. 「文字／LaTeX」をタップして出力を切り替える。🌐 はキーボード選択画面を開く。⇧ は英字の大文字切り替え。⌫ 長押しで連続削除。

日本語のかな漢字変換は行わない。🌐 で普段使っている日本語キーボードを選ぶ。

## プライバシー

インターネット権限を要求せず、入力履歴は保存しない。Android は一般的なキーボードの有効化時に入力内容についての警告を表示する。本アプリは入力内容の送信機能を持たない。設定（出力形式・キーの高さ）のみ端末内に保存する。

## 開発とビルド

外部ライブラリや Gradle を使わず、Android SDK の aapt / d8 / apksigner と JDK 17 があれば `bash ci/build.sh` で署名付き APK を作る。`ANDROID_HOME` または `ANDROID_SDK_ROOT` と `JAVA_HOME` を設定する。初回は作業ディレクトリに開発用署名キーを生成する。再インストールで更新するには同じ署名キーを使う。Play ストア配信用の署名ではない。
